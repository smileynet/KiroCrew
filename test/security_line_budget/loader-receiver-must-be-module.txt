A code-loader name written as a method (`re.compile`) was resolved as the builtin
by its bare word alone, so a regex pattern naming the product tripped the mint
check. The fix narrows `compile` by its ARGUMENT, on a payload that PARSES. A
`compile` method (or its alias or grouped form) off a proven non-owner module
whose first argument is a plain string literal that does not itself name the
package is inert regex data, so the console-script name match is skipped while the
mint-surface and product-import checks still run. A COMPUTED first argument
(`open(shutil.which('kirocrew')).read()`) stays denied whatever the receiver is at
run time, which closes the module-cache-swap and attribute-rebind class without a
spelling regex. The real builtin reached by a grouping, getattr or a rebound alias
is never skipped. A heredoc body is word-split with its quotes stripped, so no
argument can be read and no receiver is proven: a heredoc loader naming the
product is denied, as on base.
